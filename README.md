# Beyond the Five Horizons (Stage 2 — Elysium)

Minecraft Java Edition **1.21.1** | **Fabric** | **Java 21**

## Реализовано на Этапе 2 (Элизиум)
- **Измерение Элизиум** с мульти-шумовой генерацией 4 биомов: Светящийся лес (`luminous_forest`), Сад гигантов (`garden_of_giants`), Мёртвые заросли (`dead_thicket`), Кристальные поляны (`crystal_glades`).
- **6 процедурных генераторов мира**: колоссальные полые деревья с корнями, гигантские цветы, кристальные шпили, почерневшие заражённые деревья, корневые мосты и светящиеся бирюзовые озёра.
- **9 уникальных структур Элизиума**: 3 малых (`elysium_shrine`, `glowing_gazebo`, `root_arch`), 2 подземелья (`overgrown_crypt`, `blighted_hollow`), 2 крупных (`ancient_garden`, `root_temple`), арена босса (`temple_of_first_seed`) и секретное хранилище в гигантском дереве (`hollow_titan_vault`).
- **Механика Эволюции и Заражения**: Эволюционирующий росток (4 стадии), Ночноцвет (раскрывается и светится ночью), Отзывчивый бутон, Восстанавливающий мох, Заражённая почва, Источник заражения и Очищающий нектар.
- **Двусторонний портал в Элизиум**: рамка из Замшелого камня Элизиума или Замшелых каменных кирпичей активируется Очищающим нектаром (работает в обе стороны).
- **4 моба с моделями, анимациями и AI**: Светляк, Корнеход, Лепесточник, Древесный страж.
- **Босс — Сердце Леса**: 3 фазы, шкала босса, призыв через Алтарь Первого Семени (с Живой эссенцией), механика Бутонов Жизненной Силы (щит и лечение босса до их уничтожения), награда — артефакт **Сердце Элизиума**.
- **Снаряжение и строительство**: полный набор древесины Элизиума, кирпичи, стекло, фонарь, Живой клинок, Посох корней и комплект брони Элизиума.

## Сборка
```bash
gradle build
```
Итоговый JAR: `build/libs/beyondfivehorizons-0.2.0-stage2-elysium.jar`.
